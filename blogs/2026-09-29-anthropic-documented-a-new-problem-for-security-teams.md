An attacker built AI agents designed to rebuild malware whenever security tools flagged it. In a separate operation, a suspected ShinyHunters affiliate went from a stolen developer token to full administrative control of a victim's cloud environment in about three hours. Anthropic documented both operations in its September threat report.
