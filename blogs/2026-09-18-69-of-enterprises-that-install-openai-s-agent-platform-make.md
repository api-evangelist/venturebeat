Enterprises that use OpenAI's agent platform are far more likely to build on it than enterprises that use Anthropic's, according to new VB Pulse data from August. Of the 75 enterprises that have OpenAI's Agents SDK or Responses API somewhere in their agent stack, 52, or 69%, name it their primary orchestration platform. Of the 45 that have Anthropic's Claude Platform and Agent Skills, 17, or 38%, do the same.
